# Chlorella Vision — PRD v1.1 (승인본)

- 승인일: 2026-11-14
- 프로젝트: 카카오 AI 루키캠프 지원용 연구형 이미지 처리 웹앱
- 제품 상태: V1 프로토타입 제작, 사용자·연구 검증 진행 전

## 승인된 기능과 범위

1. 공개 CIDACC distinct 클로렐라 이미지부터 분석한다.
2. PC 웹브라우저를 지원한다.
3. Python + Streamlit + OpenCV를 사용한다.
4. 컬러(녹색) 및 회색조 이미지를 분석한다.
5. 사진 전체의 세포 후보를 자동 검출하고 수를 표시한다.
6. 민감도와 최소·최대 크기를 조절한다.
7. 자동으로 표시한 세포를 **클릭으로 삭제**하거나 미검출 세포를 **클릭으로 추가**한다.
8. **자동 결과를 숨긴 별도 독립 수동 계수**를 유지한다.
9. 자동/수동/수정 후 계수값을 별도로 보존하고 오차율을 계산한다.
10. 주석 PNG와 결과 CSV를 다운로드한다.
11. **실제 공개 이미지 10장부터** 검증표를 작성한다.
12. **뭉친 세포를 억지로 개별 계수하지 않고**, 실패 사례를 기록한다.
13. 현재 버전은 학습형 AI가 아닌 전통적 이미지 처리다. 이후 학습 모델을 추가한다.
14. AI가 코딩을 돕고 학생이 테스트·수정·검증한다.
15. GitHub 업로드 → Streamlit Community Cloud 배포를 목표로 한다.
16. 제출 구성은 앱 링크, 짧은 시연 영상, 검증표로 한다.

## 완료 기준

- 실제 CIDACC 이미지 10장에 대해 독립 수동 계수를 작성하고 10장 검증표를 저장할 수 있어야 한다.
- 오탐지/미탐지/불확실 영역을 정직하게 기록한다.
- 실제 앱 사이트 링크를 다른 PC에서 열어 이미지 업로드·편집·저장까지 시연할 수 있어야 한다.
- 학생이 사용한 AI 도구, 직접 테스트한 내용, 실패와 수정 기록을 남긴다.

## 배포/검증 이전 단계의 제한

V1 코드가 작성되었다고 해서 실제 CIDACC 검증이나 웹 배포가 완료된 것은 아니다.
실제 데이터는 이용자가 직접 다운로드해야 하며, 현재 ZIP에는 합성 데모 이미지 2개만 포함한다.
