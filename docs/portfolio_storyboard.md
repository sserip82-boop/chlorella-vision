# 시연 영상 구성안 (60~90초)

**현재는 제작 예정 시나리오입니다. 실제 촬영·실험 전에 성공 수치를 적어 넣지 마세요.**

| 시간 | 화면/장면 | 말할 핵심 내용 |
|---|---|---|
| 0–15초 | 클로렐라-DO 연구 사진·문제 소개 | 같은 부피라도 세포 수가 달라 실험 비교가 어렵다고 느꼈다 |
| 15–30초 | CIDACC 공개 이미지 업로드 | 공개 연구 자료로 이미지 처리 프로그램을 만들었다 |
| 30–45초 | 자동 탐지 위치 표시 | 자동으로 셀 수 있지만 불확실한 영역이 나온다 |
| 45–60초 | 사람의 추가·삭제, 독립 수동 계수 | 자동 결과를 그대로 믿지 않고 검증한다 |
| 60–75초 | 실제 검증 10장 CSV | 수동 계수와 오차를 비교했다 (실측치 필수) |
| 75–90초 | 실패 사례와 후속 모델 계획 | 겹침·흐림 한계를 학습형 AI로 개선하고 싶다 |

포트폴리오 표기 예시: **AI 코딩 도구를 활용해 프로토타입을 만들고, 학생이 직접 테스트·수정·검증했다** (실제로 수행한 후에만 사용).
